Privacy Policy

Webisaurus is a free, open-access polyglot syntax reference and language comparison tool.

🔒 100% Fully Self-Hosted Platform:

This application is fully self-hosted on private infrastructure. Your data does not go anywhere: no query searches, code comparisons, or personal data are collected, sold, or transmitted to external third-party data brokers.

Effective Date: November 1, 2026 • Version 1.1

1. Client-Side Architecture

Webisaurus operates as a client-side web application. All programming language concepts, syntax examples, and comparison datasets are downloaded to your browser and processed locally using JavaScript. Your search queries and selected language comparisons remain entirely inside your browser.

2. No Artificial Intelligence / Third-Party AI Models

Webisaurus does not use artificial intelligence inference or external AI APIs. We do not send your searches, code snippets, or browser context to OpenRouter or any third-party AI provider. All code comparisons and syntax definitions are curated, static reference tables.

3. Cookies & Local Storage

Webisaurus does not use tracking cookies. We only use browser localStorage to remember your theme preference (dark or light mode) and optional cache keys for offline browsing capability.

4. Server Logs

Our self-hosted Nginx web server records standard transient connection logs (IP address, user agent, request timestamp) solely for DDoS mitigation, system performance, and cache management. These logs are never shared or combined with personal identifiers.

5. Privacy Inquiries & Contact

If you have questions or data rights requests regarding this self-hosted application, contact us at nevatalapp@gmail.com.
